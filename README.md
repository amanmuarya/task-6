# Laundry Services Landing Page

A modern, responsive landing page built for a laundry and dry cleaning service. 
This project is a front-end implementation based on a UI design mockup, featuring a clean layout, a fully functional navigation bar, and an engaging hero section.

## 🚀 Features

* Responsive Design:

* Modern Layout:
 Built using CSS Flexbox for efficient and clean positioning.
 no use margin and padding for perent class 

* Separation of Concerns:
 Clean, well-commented HTML and CSS split into separate files for easy maintenance.

* Interactive UI Elements:
Includes smooth transition effects on navigation links and call-to-action buttons.

* Clean Typography & Colors:
 Uses a soft, professional color palette suitable for a cleaning/laundry service.

##  Technologies Used

* HTML--:
For the semantic structure of the web page.

* CSS--:
 For styling, layout (Flexbox), and responsive media queries.
